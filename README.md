■作品名

Glory Gallop

■作品概要

このゲームは、競馬シミュレーションゲームで、観戦モードと、騎乗モードの大きく2つのゲームモードがあります。
観戦モードでは、レースの情報や競走馬の情報から、どの馬が勝つのかを予想し、馬券購入し、所持金額を増やすことが目的になります。
騎乗モードでは、競馬のジョッキーとなり、競走馬を上手く乗りこなして、1着でゴールすることを目指すレースモードとなります。

■観戦モードの遊び方

レース結果の予想を行い、馬券を購入し、的中させて所持金額を増やすことが目的のゲームです。

プレイヤーはレース開始前に、レースの開催条件や競走馬の情報を確認し、そこから購入する馬券を決めます。

レース開始前の出走馬一覧の項目からは各馬の詳細情報を確認することが可能で、左右入力で表示する馬を変更することが出来ます。

レース開始前の馬券の項目から馬券を購入することが出来ます。
※現在は、単勝と複勝のみ購入が可能で、他の券種は今後実装予定です。

馬券の券種を左右移動と決定ボタンで選択し、そこから購入する競走馬の番号を同じく左右移動と決定ボタンで選択します。
複数の馬の馬券を同時に買うことが出来るので、沢山買うことで、馬券を当たりやすくすることが出来ます。
購入する馬券には、競走馬の番号と、当たった際に返ってくる金額の倍率が書いてあります。
購入する馬券を決めたら、下の確定ボタンを押し、次のページに進みます。

確定ボタンを押すと、購入する馬券の一覧が表示されます。
ここでは、馬券にカーソルを合わせ、決定ボタンを押して選択している状態で上下左右キーを押すことで、購入する金額の変更を行うことが出来ます。
金額の調整が完了したら、右の購入ボタンを押すことで、購入が確定します。

購入した馬券は一覧で見ることができ、ここから他の馬券を買い足すことも可能です。
馬券の購入が済んだら、一番下のスタートの項目を選び、決定ボタンでスタートが出来ます。

レース中は特に操作することはなく、1着の馬がゴールすると残りのレースを早送りで見られます。
全馬がゴールすると、全馬の着順、当たった馬券の組み合わせ、そして、実際に自分の買った馬券が当たったかどうかを確認することが出来ます。

高額馬券の的中を目指し、所持金をたくさん増やしましょう。


■馬券の券種の説明

単勝：選んだ馬が1着なら的中
複勝：選んだ馬が1～3着以内なら的中


■騎乗モードの遊び方

プレイヤーは加減速、左右移動、鞭を入れるなどのアクションを駆使して乗っている競走馬を勝利へと導きます。

左上のUIでは、残り距離や現在順位、現在速度、スタミナなどの各種情報が表示されます。

スタミナは速く走れば走るほど大量に消費します。
スタミナが切れると速度が大幅にダウンするので、残り距離を見てスタミナが切れないように速度を調整しましょう。

鞭を使うと、馬がスタミナ切れで減速し始めても粘らせることが出来ます。
スタミナが切れたタイミングで上手く使いましょう。

左上の順位がオレンジ色になっている際は、濃い緑色のブーストゲージが溜まります。
ブーストゲージはスタミナの代わりに使うことが出来るので、溜めれば通常よりも長く走れます。

コーナーでは外に行けば行くほどロスが大きくなるので、なるべく内側を走るのがおすすめです。

上手く競走馬を操って1着を目指しましょう。


■こだわったところ

・実際の競馬の脚質を再現するために、適正ポジションシステムを追加
　適正ポジション内だとスタミナの代わりになるブーストゲージを溜められるようにしました。
　ポジションを各馬ごとに変えることで逃げ～追込までの脚質を出来るようにしました。

・加速ボタンを長押しではなく連打にすることで、実際のジョッキーが馬を走らせる時のような　　　激しいアクションに似た気分を味わえるようにしました。

・馬の足先が地面に着いた瞬間にコントローラー振動を起こすことでリアルな振動感を演出しました。

・敵AIが他の馬を追い抜く際は接触が起きないように外から周りと距離を取って追い抜くようにしました。

・馬券購入時のオッズは過去の成績や馬の調子のほかに、連勝するとより人気になったりなど複数の要因で変化させ、実際の競馬のオッズの動きを再現出来るようにしました。

・競走馬に調子のパラメータを追加しました。
　レースごとに変化させることによって、同じ展開が繰り返されることを防ぐようにしました。
　事前に陣営コメントから知ることが出来るようにしたので、馬券を購入する際は馬の調子を見抜くことが必要になり、ゲーム性が増えました。

・観戦時のカメラはいろいろな馬を映し、動きを持たせるようにしました。
　カメラを動かすことでプレイヤーに退屈させなくするほか、現在の状況をより分かりやすく伝えられるようになりました。
